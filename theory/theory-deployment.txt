Чтобы локально развернутое приложение временно развернуть на удаленном сервере, можно использовать, например, следующие
туннели:
1. serveo.net (команда на сайте).
2. localhost.run (команда на сайте).
3. pinggy.io (команда на сайте).
4. ngrok.com (требуется регистрация и установка dev зависимостей или приложения).
5. theboroer.github.io/localtunnel-www (требуется установка dev зависимости).
6. tuna.am.

Инструкция для tuna.am:
1. Зарегистрироваться на сайте tuna.am.
2. Запустить команду через PowerShell "winget install --id yuccastream.tuna ; powershell".
3. Перезапустить PowerShell.
4. Запустить back-end приложение.
5. Запустить команду через PowerShell "tuna config save-token your_token", где "your_token" это токен, который можно
взять на сайте.
6. Запустить команду через PowerShell "tuna http port", где "port" это порт, на котором запущено back-end приложение.
