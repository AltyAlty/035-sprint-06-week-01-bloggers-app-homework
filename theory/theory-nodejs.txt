Импорты с побочными эффектами (Side-effect imports) - это импорты не с целью получения каких-то переменных, а с целью
выполнить код в каком-то файле. Такой импорт что-то делает с глобальным состоянием приложения, даже если в итоге никакие
переменные не используются из него. Примеры импортов с побочными эффектами:
1. import 'dotenv/config' - внутри этого файла лежит код, который читает файл ".env" и записывает все переменные оттуда
в глобальный объект "process.env". Это побочный эффект на глобальное окружение Node.js.
2. import 'reflect-metadata' - библиотека reflect-metadata добавляет полифиллы в глобальный встроенный JS-объект
"Reflect".

Cron - это стандартная система планирования задач по времени в UNIX-системах, которая позволяет запускать скрипты или
команды в указанное время по расписанию. В Node.js нет встроенного Cron, поэтому используются сторонние библиотеки,
которые эмулируют синтаксис Cron, но работают внутри Node.js процесса.

/*--------------------------------------------------------------------------------------------------------------------*/

BullMQ - это библиотека для управления очередями задач в Node.js, построенная на Redis. Используя эту библиотеку можно
отдавать тяжелые задачи на выполнение в очередь, например, отправка письма или редактирование изображения, чтобы задача
обрабатывалась в фоне, пока клиент может продолжать делать другие действия.
